REPO INVENTORY — every file and what it does
=======================================================================

ROOT
----
README.md              Main doc: architecture overview, config, token table,
                       demo flows, scripts index, test suite guide.
requirements.txt       Python dependencies (FastAPI, uvicorn, anthropic, crypto, ...).
.env.example           Environment template: data dir, purpose-separated keys,
                       gatekeeper mode/model, demo clock. Never holds real secrets.
.gitignore             Ignores runtime data (data/, __pycache__, .env, caches).
.claude/settings.json  Claude Code session settings (plugins). Tooling, not product.

fileguard/  (the gateway — the product)
---------------------------------------
__init__.py            Package; CLEARANCE_ORDER / CLEARANCE_NAME constants.
config.py              Central config: data dir, keys, DB paths, gatekeeper mode/model.
db.py                  Central SQLite: schema, append-only audit log with hash chain
                       + UPDATE/DELETE-blocking triggers, side table, log helpers.
security.py            Crypto core: AES-256-GCM content store, HMAC session grants,
                       Ed25519 receipts/checkpoints, salted-hash commitments.
models.py              Shared dataclasses: ItemRef, Item, Unit, ACLSnapshot, ScopeGrant.
connector.py           Connector protocol/base: changes()/fetch()/fetch_acl() contract
                       the five connectors implement.
connectors/__init__.py Connector package exports.
connectors/factory.py  build_connectors() — one connector per platform; identity
                       bridge (chat user -> Company A employee); uploads reads DB directly.
connectors/confluence.py  Confluence connector (simulator client, native ACL semantics).
connectors/jira.py        Jira connector (projects/issues).
connectors/slack.py       Slack connector (conversations/history).
connectors/drive.py       Drive connector (files).
connectors/uploads.py     Uploads connector: reads central DB + content store directly
                          (no simulator); fetch() parses files into Units with
                          base_clearance+groups ACL.
sync_engine.py        Sync engine: connector -> unified index (index.db), sync_state
                      cursors, reference-only (no content in the index).
file_index.py         LEGACY (see top): list_files discovery — clearance+group
                      filtering with hidden_counts; still wired (upload page,
                      gateway route).
search.py             search tool: ACL-prefiltered reference-only search over the
                      unified index; uploads native-ACL enforcement; hidden_counts
                      (only for natively-allowed items withheld by a lower ceiling);
                      abuse-guard integration.
auth_checker.py       Live can_access: per-platform permission re-check at query
                      time (permission epoch aware).
freshness.py          Freshness gate: index staleness + current_version comparison.
pipeline.py           run_pipeline: get_content flow — access check -> freshness ->
                      gatekeeper -> extraction -> confirmation gate -> grounding
                      check -> signed receipt.
gatekeeper.py         Gatekeeper LLM role: submit_spans tool-only output, ref
                      validation (can only narrow), fail-closed.
grounding.py          Grounding check + delivery-shape classification
                      (excerpt / stitched / none); unverifiable content degrades
                      to the verbatim spans.
abuse_guard.py        Deterministic need-to-know guard: per-message budgets,
                      broad-search / empty-flood / denied-flood patterns.
span_extractor.py     Verbatim span extraction + hash pinning from selected units.
session_service.py    Session lifecycle: ScopedGrant issue/verify, pending
                      top-secret confirmations (nonce), message budgets.
identity.py           Identity directory: chat users, personas, clearances, groups;
                      container overlay policies (containers.yaml).
audit_query.py        Auditor-facing query layer over the audit log (filters, CSV).
audit_view.py         Audit console view helpers (rows, per-entry formatting).
audit_restricted.py   Restricted-field commitments: salted hashes, plaintext side
                      table, purge with chain verifiability intact.
checkpoint.py         Signed audit checkpoints + RFC 3161 timestamp anchoring
                      (TSA material in data/tsa/; temp artifacts at runtime only).
store.py              Encrypted content store: save/load plaintext, content-addressed
                      by SHA-256 (the file_id).
parsers.py            File parsers: PDF/XLSX/DOCX -> typed spans; detect_kind().
stub_models.py        Deterministic test/CI stubs for gatekeeper + answering model
                      (no LLM API; used when GATEKEEPER_MODE=test).
gateway.py            The gateway itself: tool dispatch (search / get_content /
                      list_files), policy overlay application, audit emission,
                      policy_mismatch warnings.
